# Fabrica Positioning Statement & Executive One-Pager

**Audience:** founders, builders, operators, lean teams, and project managers

## Positioning statement

For **founders, builders, and operators** who need to run and grow with AI, **Fabrica is the desktop agent platform** that manages specialist CLI agents — Claude Code, Codex, OpenCode, Cursor, Devin, and others — through local terminals, without requiring technical fluency to direct them. Instead of raw CLI tabs, Fabrica transforms the terminal experience into a Slack-style channel interface where agents discuss approaches, delegate sub-tasks, and report progress in plain language. The UI is agentic and event-driven — work triggers on events (a task completing, a budget threshold approaching, an approval gate opening), not manual polling. Over time, the interface adapts to user behaviors, preferences, and operational patterns, becoming more personalized and more useful with every run. Unlike cloud automation tools or standalone coding assistants, Fabrica gives you platform-level control: set the brief, watch agents collaborate in dedicated channels, reference a shared knowledge vault, approve consequential steps, cap the budget, and run business operations continuously — 24/7 customer support, content pipelines, ecommerce management, and more — all from one desktop interface.

**Short form:** Your business, automated. Your judgment, still in the loop.

## Executive one-pager

### Direct the crew. Keep the call.

#### Problem

Founders and operators are expected to build, ship, market, and run their business simultaneously — but AI tools are still siloed. A coding agent runs in one terminal; a browser agent runs somewhere in the cloud; a workflow tool connects APIs. Nobody gives you one place to manage all your CLI agents, let them collaborate with each other, share a common knowledge base, review their work at structured approval gates, and run continuous business operations — customer support, ecommerce, content — without giving up control or visibility into cost.

#### Solution overview

Fabrica is a desktop platform for managing CLI agents. It spawns and steers Claude Code, Codex, OpenCode, Cursor, Devin, and other CLI agents through local terminals according to your brief. Agents collaborate with each other in Slack-like channels — they can delegate, argue, and align — and every agent references a shared knowledge vault and business roadmap: a folder of documents and a plan that becomes the source of truth for the entire operation. Smart agents immediately know what and when each one needs to do — no manual orchestration required. Use approval gates, budget caps, and risk tiers to keep consequential work within your rules. Spend tracking is available for CLI agents that expose quota data (Claude Code, Codex, OpenCode); for others, Fabrica gates by approval rather than cost. Connect to n8n via the native plugin to extend any agent workflow to 400+ SaaS integrations without writing code.

#### Key differentiators

- **Manages your CLI agents — not a model itself.** Fabrica orchestrates Claude Code, Codex, Cursor, Devin, and other CLI agents via local terminals. Your provider keys go directly to the provider — never through Fabrica. Spend tracking works for agents that expose quota data; approval gates protect everything else.
- **Business-first UI, not raw terminals.** Fabrica transforms CLI agent sessions into a Slack-style channel interface. Agents discuss, delegate, and report in plain language — no terminal fluency required. The UI is event-driven, triggering on task completions, budget thresholds, and approval gates rather than manual polling.
- **Adaptive interface that learns with you.** The more you use Fabrica, the more the interface reflects how you actually work. It learns from your behaviors, preferences, and operational patterns to surface priority alerts, relevant views, and the controls that matter most — a living system, not a static layout.
- **Agents collaborate, not just execute.** Agents communicate in dedicated channels, delegate sub-tasks, and reference a shared knowledge vault and business roadmap — your documents become the common source of truth. Smart agents immediately know what and when each one needs to do; users don't orchestrate manually.
- **Run the business continuously.** Move beyond the prototype to 24/7 operations, including customer support, ecommerce management, and content pipelines, through human-governed agent workflows.
- **Autonomy with accountable control.** Every consequential action passes through an approval gate. Hard budget stops and risk-tiering ensure work remains within your rules.
- **Connect everything via n8n.** Native n8n plugin gives every Fabrica workflow access to 400+ SaaS integrations — making n8n a capability multiplier, not a competitor.
